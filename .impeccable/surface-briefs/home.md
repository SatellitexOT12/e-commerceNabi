# Surface Brief: Home

## Direction Contract

**THESIS:** El Taller del Pastelero — un sistema visual que celebra el proceso artesanal visible. No es una tienda genérica; es el espacio donde se crean los dulces. La tipografía serif elegante evoca tradición, los colores cálidos evocan ingredientes naturales, y el espaciado generoso permite que cada producto respire.

**OWN-WORLD:** Rosa pastel (#f8bbd9), crema (#fef7f0), chocolate (#5d4037). Tipografía: Playfair Display (serif elegante) para títulos + Inter (sans limpia) para cuerpo. Cards con bordes sutiles rosa, botones con carácter, inputs con personalidad. Texturas de papel crema, bordes decorativos sutiles, sensación de hecho a mano.

**STORY:** El usuario llega a un taller artesanal, no a una tienda. Cada elemento visual comunica "hecho con cuidado". La tipografía serif evoca tradición artesanal, los colores cálidos evocan ingredientes naturales, y el espaciado generoso permite que cada producto respire. El hero debe comunicar inmediatamente "pastelería artesanal de calidad".

**FIRST VIEWPORT:** Hero con tipografía serif grande (Playfair Display), imagen de producto apetitosa, y un CTA claro "Ver Productos". El hero ocupa el viewport completo con un gradiente sutil de rosa a crema. Debajo, carrusel de productos destacados con cards elevadas.

**FORM:** Mejora incremental — mantener estructura actual (hero, carrusel, historia, features, contacto) pero elevar tipografía, componentes y jerarquía visual. Seed key: 3c780f36.

**FINISH:** Unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Scope

- **Surface:** Home (página principal)
- **Mode:** Persuade
- **Audience:** Personas en Cuba buscando dulces artesanales
- **Job:** Explorar catálogo, seleccionar productos, personalizar con agregos, realizar pedido
- **Constraints:** Mantener estructura actual, paleta de colores, funcionalidad existente
- **Build path:** comp-first (configurado en .impeccable/config.json)
